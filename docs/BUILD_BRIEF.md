**VCC WEBSITE 2026**

**Developer & Designer Build Brief**

*Valor Christian College*

**PURPOSE**

Turn the 2026 website update notes into a clear, buildable blueprint.
This brief separates site structure, page goals, copy, design direction,
links, and action items.

# 1. Website Vision

Attract new students and better serve current students. The website
should be the best first impression for prospective students: help them
get excited about Valor, find the information they need, and take the
next step toward applying. At the same time, it should be a go-to
resource for current students, making it easy to access the student
portal, campus resources, important updates, and other essentials
throughout the school year.

**Decision filter:** Every page should either help someone become a
Valor student or help a current student thrive.

# 3. Global Design Direction

- Prospective-student first: inspirational, personal, clear, and easy to
  scan.

- Reduce long-form text where possible; use short sections, images,
  video, quotes, icons, cards, and testimonials.

- Tell a story rather than presenting pages like institutional letters
  or directories.

- Use consistent CTA language across pages: Apply Now, Request
  Information, Schedule a Visit, Speak with Admissions.

- Use modern card layouts for programs, faculty, pathways, and benefits.

- Make current-student utilities easy to find, especially Student
  Portal.

- Overall Valor feeling: Spirit-filled, purpose-driven, legacy-minded,
  transformational.
